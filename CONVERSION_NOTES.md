# Conversion notes & issues found

This file records the editorial decisions made while converting the Word
thesis to LaTeX, and---more importantly---a list of **substantive
inconsistencies that were found in the source document**. Data values were
reproduced **faithfully** from the Word file; nothing was silently changed.
Please review the items in §2, since several are genuine errors in the
underlying manuscript that only you can resolve against your laboratory data.

---

## 1. Formatting improvements applied

- **Equations.** Every "equation" in the Word file was plain text (there were
  zero real Word equations). All have been re-typeset as proper LaTeX math:
  the fouling index `FI_IN = P_0.075 + P_20`, the field-stress and
  apparatus-stress/energy calibration, the Tukey 1.5×IQR fence, the Wadell
  sphericity, and the morphological-descriptor formulae.
- **Subscripts / superscripts / symbols.** `FI_IN`, `P_0.075`, `P_20`,
  `D_eq`, `V_ch`, `A_ch`, `K_e`, `σ`, `Ψ`, `Δ`, `κ_s`, `%ΔV`, `23rd`, etc.
  are now real math/ordinals rather than Unicode glyphs.
- **Units** are set with `siunitx` (`\qty{275}{\kPa}`, `\qty{2.76}{\g\per\cm\cubed}`,
  `\qty{147}{\J}`, `\qty{9.81}{\m\per\s\squared}` …).
- **Numbering is now automatic.** The Word file had manual numbering with
  gaps and duplicates (see §2); LaTeX now numbers all chapters, sections,
  figures, tables and equations, and auto-generates the ToC / List of
  Figures / List of Tables.
- **Citations** use `natbib` (author–year) backed by `references.bib`;
  the bibliography is generated by BibTeX.
- **Cross-references** use `cleveref` (`\cref`), so "Figure 4.2", "Table 2.1",
  "Section 3.5", "Chapter 5" always resolve to the correct number.
- **Figures** keep their original sequence and relative on-page size
  (widths set as the same fraction of the text block as in Word). Multi-image
  rows (e.g. the morphology-parameter pair) use `subcaption`.
- Professional thesis styling: Times-like `newtx` fonts, A4 with a binding
  margin, 1.5 line spacing, running heads, hyperlinked PDF with bookmarks,
  and a syntax-highlighted Python listing (Appendix B).

## 2. Substantive issues found in the source (NOT changed — please verify)

1. **Test-label mapping is inconsistent across tables.** The map from test
   number (T1–T9) to configuration differs between Table 3.3 (test matrix),
   Table 4.1 / Table 5.1 (results), and Appendix A.1. For example T1 is
   `UR-FB-300` in Table 3.3 but `PUBM-FB-300` in Tables 4.1/5.1. All three
   were reproduced exactly as in the Word file.
2. **Table 4.1 contains a duplicate configuration:** both T4 and T7 are
   labelled `UR-RB-450` (with different `FI_IN` of 1.960 % and 3.386 %), and
   T2 is labelled `RUBM-FB-450` even though the FB-450 cells were said to be
   omitted from the matrix.
3. **T4 drop height conflicts:** Appendix A.1 lists T4 as `UR-RB-LH` (300 mm),
   but the Chapter 5 discussion and Table 5.1 treat T4 as a 450 mm (HH) test.
4. **Two different fouling datasets.** `P_0.075`, `P_20`, and `FI_IN` differ
   between Table 4.1 and Appendix Table A.3 (e.g. T1: 0.533 % vs 0.62 %;
   T7: 3.386 % vs 2.69 %). Both tables were reproduced verbatim.
5. **Particle density:** the text says 2.76 g/cm³ while Table 3.1 says
   2.78 g/cm³.
6. **Field-stress arithmetic.** The Word file wrote
   `σ = 110.25 kN / 0.11 m² ≈ 1000 kN/m² ≈ 250 kPa`, which is internally
   inconsistent (1000 kPa ≠ 250 kPa). To keep the stated 250 kPa result, the
   LaTeX uses the **rail-seat load** (≈ 27.5 kN, i.e. the wheel load shared
   over adjacent sleepers) rather than the full wheel load. Please confirm
   the intended distribution factor.
7. **Backwards inequality (Ch. 4).** The Word file wrote
   "T9 PUBM 0.972 % < T8 RUBM 0.667 %" (0.972 is not < 0.667). The sentence
   was rephrased to present both values without the incorrect inequality;
   the broader claim was left intact.
8. **Dangling references resolved.** The text referred to a "Section 3.8
   (statistical framework)" and a "Table 3.5 (twenty-two descriptors)" that
   did not exist in the file. A concise **Section 3.8** (paired t-test and
   Tukey IQR fence, both already used in Ch. 5) and a **descriptor table**
   were added so the references resolve. Please check they match your intent.
9. **List-count mismatches.** "Four limitations" preceded three bullets and
   "Five directions" preceded four; the lead-in numbers were matched to the
   bullets actually present. If items were dropped, please re-add them.
10. **Citations missing from the reference list.** These appear in the body
    but were not in the Word reference list, and their full details could not
    be verified, so they are rendered as plain text (not linked to the
    bibliography): *Navikas et al. (2018)*, *Koohmishi & Palassi (2017)*,
    *Bassey et al. (2020)*, *Bian et al. (2020)*, *Liu et al. (2022)*,
    *Indraratna et al. (2019)*, *McDowell (2002)*. Please add them to
    `references.bib` and switch each to `\citep{...}` / `\citet{...}`.
11. **References added for completeness.** Seven well-known works cited in the
    body were missing from the list and have been added to `references.bib`
    (search for `[ADDED]`): Cundall & Strack (1979), Lim, McDowell & Collop
    (2004), Lim & McDowell (2005), Werkmeister et al. (2001), Lichtberger
    (2005), Tordesillas (2007), Alabbasi & Hussein (2021). Please verify these
    details against your sources.
